# Welcome to the The Backprop Blog!

>  🧠 Lucas Martinez's AI & ML Blog

Welcome to my personal blog — where I dive into deep learning, transformers, computer vision, and all the cool AI stuff. If you're into intuitive explanations, and visual guides, you're in the right place.

## 📚 What You'll Find Here

This blog is written to help you understand, not just to tell. Each post aims to balance intuition, math, and real-world examples. Some of the highlights:

- ✨ **Transformers in Vision** — from DETR to DINO
- 🔍 **Attention Mechanisms** — self-attention, multi-head, and beyond
- 📐 **Classic CNNs** — explained clearly, with examples
- 🚀 **And more** in comming! 

All written in Markdown + Astro, with math rendered using LaTeX and visuals to make the concepts click.
